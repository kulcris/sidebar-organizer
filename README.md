# Disable Sidebar Icons

Keep your RuneLite sidebar tidy. Hide icons you rarely use and drag the rest into your preferred order—all while keeping the plugins running.

## How to use

Open **Sidebar Icons** in the sidebar:

- Uncheck an icon to hide it; check it to show it again.
- Drag the grip beside an icon up or down to change its position.
- Use the search box to find an icon.
- **Show all** restores hidden icons.
- **Reset order** restores the default order without changing which icons are hidden.

Your choices save automatically for each RuneLite profile. Sidebar panels and toolbar actions can be reordered within their own groups.

## Hide this plugin's icon

Open RuneLite's plugin list, click the gear beside **Disable Sidebar Icons**, and enable **Hide own sidebar icon**. Turn it off in the same settings to show the icon again.

RuneLite's Configuration icon stays available so you can always reach these settings.

## Good to know

- Enable a plugin before looking for its icon. Some icons only appear after login.
- New icons appear automatically; **Refresh** checks immediately.
- Hiding an icon keeps its plugin running. If its panel is open, hiding the icon closes that panel.
- Disabling this plugin restores RuneLite's normal sidebar layout.
